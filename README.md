# I SEE U — dépôt de diffusion

`iseeu-version.json` est le manifeste que l'application lit quand on appuie sur
le bouton de mise à jour. Les APK ne sont pas versionnés ici : ils partent en
pièce jointe de release (`iseeu-v<version>`).

Publication : `/Users/Shared/iseeu/publier.sh "notes de version"`.

Adresse lue par l'app :
https://mailpersoys-droid.github.io/iseeu-apk/iseeu-version.json
